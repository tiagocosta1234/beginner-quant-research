# PREREG - idea 1: volatility-aware sizing (the trader 2026-10-13: "(original wording omitted)"), written before the run
Goal: raise P(session ends +2,000) (and P(pass)) by sizing each entry with a causal volatility factor on top of the base policy. Locks: +2,000 / -1,500, MT5 broker rules, signals SDB + XAU5 (MT5 broker-era gold), 1-minute simulator session_lab.
Factors, all known at entry (minute closes of the same bars): F1 = ADR20/ADR120 (volatility regime); F2 = previous day's range / ADR20; F3 = hour-of-day seasonal vol share (mean |1-min move| by server hour, normalised to mean 1, taken from the training years); F4 = realised last-60-minute vol / the seasonal expectation for that hour; F5 = clip(1.5 - range_so_far_today / ADR20, 0.3, 2) (size down once the day has used its range).
Size multiplier = clip(F1^a1 * F2^a2 * F3^a3 * F4^a4 * F5^a5, 0.4, 2.5), exponents in {-1, 0, 1} (negative = inverse / target-vol style) for F1..F4 grouped as a in {-1,-0.5,0,0.5,1}: grid 5^4 for F1-F4 times F5 exponent {0,1} = 1,250 variants per base policy. Base policies: SAFE (L1500, m0 1.5, constant) and D (L1500, m0 3, k 1, H_stop 3).
Selection on TRAIN (FT 2022-24 trades as history, MT5 broker rules, used only as training data; reported results are MT5 broker only): maximise the share of sessions ending +2,000 subject to the account-level breach <= 10% (bootstrap, 20,000 paths) and up/(up+down) not below the base policy's ratio. Top 3 per base are run ONCE on MT5 broker 12 months.
Verdict: an idea counts if on the MT5 broker test it raises the +2,000 session share over its base by >= 2 points WITHOUT lowering up/(up+down) or raising breach by more than 2 points. Caveats: the hour table uses the whole training span (stable seasonal pattern), 12 months of MT5 broker gold, replay of tester fills.
