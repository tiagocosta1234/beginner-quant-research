# PREREG - idea 2: position management inside the session (the trader 2026-10-13: "avanca com a ideia 2"), written before the run
Aim: raise P(session ends +2,000) with the signals we have (SDB + XAU5), by changing how winners are handled; locks +2,000 / -1,500, MT5 broker rules, 1-minute simulator.
Levers (all causal, simulated on the minute path): (1) BOOST b in {0, 0.5, 1, 2}: each new entry sized x(1 + b * max(day PnL, 0) / 2,000) (anti-martingale: more size as the day goes right); (2) RUNNER mode in {off, same-day, two-day}: a trade that closes in profit is not closed at the EA's exit but kept until the price returns to its entry (break-even stop), or until 22:00 server of the exit day (same-day) / of the next day (two-day), whichever first; (3) ADD-ON in {off, (step 0.10 ADR20, ratio 0.5), (0.10, 1.0), (0.20, 0.5), (0.20, 1.0)}: when a trade moves +step x ADR20 in its favour, a second position of ratio x its size is opened at that quote with the same exit as the parent.
Grid 4 x 3 x 5 = 60 variants per base policy; bases SAFE (L1500, m0 1.5, constant) and D (L1500, m0 3, k 1, H_stop 3).
Selection on TRAIN (FT 2022-24 trades as history, MT5 broker rules): maximise the share of +2,000 sessions subject to account breach <= 10% (bootstrap 8,000 paths) and up/(up+down) >= the base ratio. Top 3 per base run ONCE on MT5 broker 12m.
Verdict: the idea counts only if on the MT5 broker test it raises the +2,000 share by >= 2 points over its base without lowering up/(up+down) or raising breach by more than 2 points. Caveats: runner and add-on use minute closes (bid/ask via spread), 12 months of MT5 broker gold, replay of tester fills.
