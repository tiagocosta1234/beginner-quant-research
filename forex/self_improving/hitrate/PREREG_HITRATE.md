# PREREG - gold intraday hit rate (the trader 2026-10-13: "tens que melhorar a taxa de acerto"), written before the run
Question: is there a gold rule, from MT5-native MT5 broker bars only (bid/ask OHLC, server clock), whose position reaches TP = +4/3 SL before SL more often than the 3/7 = 42.9% break-even, by a margin that survives costs and 22 comparisons?
Data: mt5\data_mt5\XAUUSD_M1_rates.parquet (MT5 broker server feed, bid and ask OHLC, 2021-12..2026-10). Windows: A 2021-12..2023-06, B 2023-07..2024-12, VAL 2025-01..2025-12, SEALED 2026 (not opened here).
Trade: one per rule per server day; signal at minute close, entry next minute open at the ask (long) / bid (short); barriers checked on bid/ask high/low (same minute both -> SL first); exit at 22:00 server on the quote if neither; SL = w x ADR20 (mean of the previous 20 daily ranges), TP = 4/3 SL; w in {0.20, 0.35}.
Rules (11): asian-break (01-09h range, first 09-20h close outside it, in the break direction), asian-fade (opposite), ldn-mom (01-10h return, enter 10:00 with it), ldn-fade, ny-mom (16:30-17:00 return, enter 17:00 with it), ny-fade, sweep (first minute whose high exceeds the previous-day high but closes below it -> short; mirror at the previous-day low -> long), trend (20-day direction at 10:00), antitrend, gap-fade (open vs previous close, if |gap| > 0.1 ADR, enter 01:05 against it), gap-follow. 22 cells.
Pass for a cell: mean R > 0 in A AND in B AND in VAL, VAL mean R >= +0.15, VAL t-stat of R per trade >= 3.0 (Bonferroni over 22 cells), VAL trades >= 150. Also reported: decided-hit rate (TP over TP+SL), timeouts, win days for the session system (TP day = +2,000 equivalent).
No tuning after the run; SEALED 2026 untouched. Caveat: 12 months of VAL with a gold bull trend; a passing cell would still need a forward test.
