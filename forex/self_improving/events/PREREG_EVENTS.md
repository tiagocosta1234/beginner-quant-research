The MT5 economic calendar (MQL5 `CalendarValueHistory`) carries actual, forecast (consensus) and previous values for every event, so, unlike the ALFRED proxy of the slow family, the surprise here is the real one and is MT5-native (deployable in an EA with the same functions).

## Data (exported read-only on 2026-10-13 from the portable tester terminal with `ExportCalendar.mq5`; copy at D:\finance\data_macro\mt5_calendar.csv)
68,353 rows 2021-12-01..2026-08-15, 1,421 events, 23 countries; times are UTC (checked: NFP at 12:30 in summer and 13:30 in winter). Used rows: importance = 3 (high), actual and forecast present, `impact` flag 1 or 2 (MetaQuotes' own classification of the surprise as positive or negative for the currency), currency in {USD, EUR, GBP, JPY, AUD, CAD, NZD, CHF}, at least 8 previous releases of the same event in the file, and time up to 2025-12-31 (2026 is never used). 1,758 usable events.
Surprise score S = +/-|actual - forecast| / sigma_event, sign by the impact flag (positive = good for the event currency), sigma_event = standard deviation of (actual - forecast) over the PREVIOUS releases of the same event only (causal). A strong surprise is |S| >= 1.0 (fixed). Counted before any price work: 328 strong events in 2022-2024 (USD 278, others 50); only two event types have >= 20 strong events in that period, so tests are POOLED, not per event type.

## Trades (fixed now)
For each strong event, the currency effect maps to assets with a fixed sign: USD strength -> EURUSD -, GBPUSD -, AUDUSD -, NZDUSD -, USDJPY +, USDCAD +, USDCHF +, XAUUSD - (the eight are averaged into one basket return per event); EUR -> EURUSD +; GBP -> GBPUSD +; JPY -> USDJPY -; AUD -> AUDUSD +; CAD -> USDCAD -; NZD -> NZDUSD +; CHF -> USDCHF -. Direction = sign(S) x asset sign (follow the surprise). Entry at the ask (long) / bid (short) of the open of the first M1 bar that starts at least `delay` minutes after the release (delay 1 or 5), exit at the bid (long) / ask (short) close of the M1 bar that closes `H` minutes after the entry (H in 5, 15, 60). Real M1 bid and ask bars (MT5 broker), no carry, no commission.

## Pools and tests
P1: all strong USD events (basket of 8). P2: all strong non-USD events (their own pair). P3: tier-1 US events, a fixed list: Non-Farm Payrolls, Unemployment Rate, Average Hourly Earnings, CPI (y/y, m/m, core), Retail Sales and Core Retail Sales, GDP, Initial Jobless Claims, ISM/S&P Global PMIs, FOMC rate decision. 3 pools x 3 horizons x 2 delays = 18 tests, Bonferroni 0.05/18 = 0.0028.
Statistic: mean net return (bp) of the follow-the-surprise trades. Null: sign-flip permutation of the surprise direction, in blocks (all events sharing one release timestamp flip together, because simultaneous events are not independent), 20,000 flips; one-sided p. A test passes DEV (events 2022-01-01..2024-12-31) if p < 0.0028 and the mean net is positive; passing tests get ONE look at 2025 (one-sided p < 0.05 and a positive mean). A placebo calendar (every event time moved +7 days, same weekday and clock time, surprises kept) is run with the identical code: 0 passes expected; if it passes anything the pipeline is broken. Nothing in 2026 is read.

## Expectations written now
Consensus-surprise reactions are among the best-documented effects in FX, but they are over within seconds and the first full minute already carries the move; after real spreads, which widen at releases, the usable remainder after a 1-minute delay is expected to be small or negative. The number of strong events is small (328 in DEV), so only a large effect can be detected. The most likely outcome is no passing test.
