# Pre-registration EURUSD-ML: one walk-forward model over every EURUSD feature family (written 2026-10-14 before any run)
the trader: "a walk-forward ML model over all these features together". EURUSD only. Prior for any survivor: about 2%.

## Samples
Server-clock decision slots at minute 05 of hours 2,4,...,18 (9 per day), Monday-Friday, 2022-03-01..2025-12-31 (script refuses 2026 unless `--hold`). Entry at the OPEN of that minute (ask long / bid short), exit 4 hours later at the open (bid / ask), slippage 0.1 bp per side; both ends are outside server hours 23 and 0. Label y = mid-to-mid EURUSD return over the 4 hours in bp. All features use bars strictly before the entry minute.
## Features (about 45, fixed)
Returns of EURUSD over 1, 2, 4, 8, 24 h; realised vol (std of hourly returns, last 24 h) and ATR14(H1)/ATR14(daily); spread at the previous bar; hour, weekday; daily state (previous completed day): z = (close-EMA20)/ATR_D, EMA20-EMA50 order, RSI(2) Wilder, close location in the day range, weekly stretch; overnight move; tick-volume ratios (3 h and 6 h versus the same window median of the previous 20 weekdays) and the signed 3 h return; cross-pair spread EURUSD minus mean(GBPUSD, AUDUSD, NZDUSD) over 6 h and 24 h; distances to the prior-day pivot, R1 and S1 in ATR_D; MT5 calendar (importance 3, USD and EUR): minutes since the last release (cap 1,440), the reaction of EURUSD around it (mid at +10 min versus -1 min, bp, only if known at the slot), minutes to the next scheduled release (cap 1,440); other markets: SP, NSDQ, XAUUSD and USDJPY returns over 4 h and 24 h.
## Models and trading rule (cells = 4)
M1 ridge (standardised features, alpha 100); M2 histogram gradient boosting (depth 3, 200 iterations, learning rate 0.05, min leaf 50, L2 1.0). Both regress y. Walk-forward, expanding window: test windows are half-years starting 2023-01-01; each model is trained on all samples whose exit is before the test window starts (no refit inside a window); no hyper-parameter is tuned.
Trading: at each slot in chronological order, if no position is open and |prediction| >= c, open sign(prediction) for 4 hours (one position at a time). c in {1.0, 2.0} bp. Cells: 2 models x 2 c = 4.
## Periods and gates
DEV = trades with entries in 2023-01..2024-12, VAL = 2025 (both strictly out-of-sample by construction), HOLD = 2026 (sealed).
Multiple testing: 4 cells + 63 earlier tests = 67, so DEV t >= 3.4 on per-trade net bp. G1 DEV mean net > +1.0 bp, t >= 3.4, n >= 100. G2 VAL mean > 0, t >= 1.65, n >= 40. G3 positive in 2023, 2024 and 2025 each. G4 calibration: 5 placebo worlds (training labels permuted within calendar months, test unchanged) run through the whole pipeline; the real best DEV t must exceed the maximum placebo best t. Also reported (not gates): out-of-sample rank IC, prediction-sign hit rate, long-only drift yardstick, by-hour table of trade P&L (the K2 lesson).
Kill rule: no variants after any run; amendments before any P&L only, written here.
