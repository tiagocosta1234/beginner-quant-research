# Pre-registration BRK-ML2 (breakout day, round 33; written 2026-10-15 14:10 local, local clock, before any code or result)
Question: no single filter worked; can a walk-forward machine-learning model, given everything known at the entry, pick a profitable subset of breakouts? Round 5 tried this on the 54,000 session breakouts (lift to about 0); this round uses the 986,184 hour-map breakouts of round 25 (46 markets x server hours 1-19, 60-minute boxes, stop at the other side, hold up to 6 h; `BRK_HOURS.parquet`).
Features (all known before the entry): class, server hour of the box, side, weekday, trading day of the month, log(box / spread), box / spread relative to the trailing median of the same market and hour (previous 60 events), trailing mean R of the same market and hour (previous 60 events, all closed on earlier days), trailing mean R of the market (all hours, previous 20 trading days), trailing mean R of the class (previous 20 days), number of same-class breakouts already filled earlier in the same box hour that day (crowd).
Model: XGBoost regression (300 trees, depth 3, learning rate 0.05, subsample 0.8), target = net R clipped to [-1.5, 4]. Walk-forward, expanding window: train <= 2022 -> test 2023; <= 2023 -> 2024; <= 2024 -> 2025; <= 2025 -> 2026 (non-clean). Each test year trades the events whose prediction is at or above the 90th percentile of that model's predictions on its own training set.
- **S1 top-decile selection.**
Gates: 1. DEV (test years 2023 + 2024 pooled) mean >= +0.05 R and t >= 1.96 (daily NW lag 1; one cell). 2. VAL (test year 2025) mean > 0 and t >= 1.65. 3. Beats the unselected events of the same test years by >= 0.05 R in DEV and VAL. 2026 reported.
Honest prior: about 5% (the information is ~0.01 R a trade on average; a model can only win if it is concentrated somewhere the single filters missed).
Amendment A1 (14:09, dry run only, no P&L seen): log(box / spread) clipped to [log 0.5, log 3000] and box / trailing median clipped to [0, 20], because a few minutes with a zero recorded spread gave values up to 1e14; a real truncation test (features rebuilt on data cut at 2024-03-13 must equal the full build) replaces the by-construction note.
Amendment A2 (dry run only, no P&L seen): the truncation test failed on 'crowd' only (ties: several markets filled in the same minute were counted in an arbitrary order). Crowd is now the number of same-class breakouts filled STRICTLY earlier in that box hour (rank with ties at the minimum).
