# forex/tools

Small research helpers from the MT5 phase:

- `make_news_file.py`: builds a calendar file of scheduled economic releases for news filters.
- `macro_brief.py`: prints a short macro summary (rates, dollar, volatility) from local data.
- `apply_x2_charts.py`: regenerates the result charts for one family of tests.
- `live_log.py`: appends forward-test calls to a CSV log before the outcome is known.
