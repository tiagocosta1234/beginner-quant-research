# forex/factor_lab

Three pre-registered cross-market tests on daily data: classic factors (`PREREG_FACTORS.md`,
`factor_test.py`), time-series trend (`PREREG_TREND.md`, `trend_test.py`), and positioning and
central-bank meetings (`PREREG_COT_FOMC.md`, `cot_fomc_test.py`, using COT reports and FOMC dates).
